Announcing LangGraph v0.2 and LangGraph Cloud!

After months of development and testing, we're excited to announce the next major version of LangGraph and the release of LangGraph Cloud.

LangGraph is a library for building stateful, multi-actor applications with LLMs. LangGraph Cloud is a platform for deploying and scaling those applications.

This release includes:

- LangGraph: new features like human-in-the-loop, subgraphs, and configurable state.

- LangGraph Cloud: production deployment with built-in observability, tracing, and hosting.

- LangGraph Studio: a new IDE for visualizing, interacting with, and debugging your graphs.

Read more in the blog post below!
